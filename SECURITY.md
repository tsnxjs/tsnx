# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.0-rc.x | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability

Kami sangat mengutamakan keamanan TSNX. Jika Anda menemukan kerentanan keamanan:
1. **Jangan** membuat issue publik di GitHub.
2. Kirimkan laporan detail via GitHub Security Advisories di repositori ini atau melalui email ke `security@tsnx.dev`.
3. Sertakan langkah reproduksi, dampak potensial, dan proof-of-concept jika memungkinkan.
4. Tim kami akan merespons dalam waktu 48 jam dan berkoordinasi sebelum rilis perbaikan publik.
